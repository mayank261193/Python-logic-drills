## Drills

| File | What it does |
|---|---|
| `drill_01_temperature.py` | It will convert temperature unit |
| `drill_02_bill.py` | It will calculate bill paid by individual person |
| `drill_03_username.py` |It will create intials and username |
| `drill_04_Remove_duplicates.py` |It will remove duplicate entry|
| `drill_05_Above_average.py` |It will filter above average students|
| `drill_06_Two_customers.py` |it will give common users of a item|
| `drill_07_Dictionary.py` |It will create dictionary based on length of word|
| `drill_08_Sort_by_price.py` |It will sort data by price in increasing order|
| `drill_09_Expensive.py` |It will pop out most expensive item from list|
| `drill_10_Messy_clean.py` |It will clean the messy list|
## How to run
First write file using code-:
%%writefile drill_01_temperature.py
It will create a file.
Use this code to this particular file-:
```
!python drill_01_temperature.py
```
Similarly create file using %%write and write code in it and run it.
